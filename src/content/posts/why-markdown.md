## A format that refuses to die

Markdown turned twenty this year. In software years, that's ancient. Most
writing tools from a decade ago are gone, and the ones that survived have
been rewritten twice. Markdown is still here, and it still opens in a plain
text editor.

That's the whole pitch.

## The cost of clever formats

Every proprietary editor makes the same trade: a smoother first hour in
exchange for a harder last year. Your notes live in a database you can't
read, behind an editor you can't script, in a file format no other app
understands. The day you want to leave is the day you find out how
expensive "free" was.

Markdown inverts the trade. The first hour is plain — no toolbar, no
canvas, no AI sidebar — and every year after gets cheaper. Your files
work in any editor, any operating system, any decade.

## What you give up

Honestly: a few things. There's no native notion of a "block," no
drag-to-reorder, no live database views. If you want those, use a tool
that has them. But keep the source text in markdown, so the day you
leave, you leave with your words.

> The best format is the one you'll still be able to read when the app
> that wrote it is gone.

## The bet

We're betting the next decade on plain text. Not because it's flashy,
but because it's the only thing we're confident we'll still be able to
open.
